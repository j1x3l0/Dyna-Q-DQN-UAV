# UAV-DRL 项目当前阶段研究报告

> 报告日期：2026-07-27
> 覆盖范围：2026-07-11 至 2026-07-27
> 目标期刊：IEEE Wireless Communications Letters (WCL)

---

## 1. 项目摘要

### 1.1 研究目标

面向 UAV 辅助无线传感器网络，提出**模型驱动分层多智能体强化学习**方法：

- 上层 MADDPG 负责 UAV 轨迹规划与传输调度（慢时间尺度）
- 下层 DQN 负责 GU 模式选择与接入控制（快时间尺度）
- Dyna-Q 环境模型生成虚拟经验，加速下层 DQN 收敛

### 1.2 核心主张

> 分层架构是主要性能增益来源（vs 单层 MADDPG 约 +17%）；Dyna-Q 的核心价值在于**样本效率**——达到同等性能所需真实交互轮次减少约 1.57 倍，而非显著抬高最终奖励天花板。

### 1.3 当前阶段

**阶段 B**（统一三算法 5 种子训练）准备中，等待 GPU 空闲启动。后续为**阶段 D**（Dyna-Q 消融实验）。目标：为 WCL 投稿提供统计上有说服力的证据链。

## 2. 已完成实验

### 2.1 早期探索（负奖励时期）

| 实验 | 日期 | 算法 | 轮次 | 奖励模式 | 结果 |
|------|------|------|------|---------|------|
| Dyna 验证 | 07-11 | MADDPG / Hier-DQN / Hier-DynaQ | 500 | 加法形式 | Hier 比 MADDPG +75.87% |
| 长训 5000 | 07-12~13 | MADDPG / Hier-DynaQ | 5000 | 加法形式 | Hier-DynaQ +63.02%，std≈2800 |
| 分层 5000 | 07-12 | Hier-NoDyna | 5000 | 加法形式 | 分层无模型对照 |

**诊断出的关键问题**：
- 奖励函数为加法形式（非论文能效比），奖励始终为负
- 噪声功率写错：代码 `1e-9 W` vs 论文 `1e-12 W`（SNR 差 3 个数量级）
- 上下层共享同一奖励，未做分离

> ⚠️ 旧实验的提升比例（63-76%）不能与新实验的正奖励结果直接合并或对比。

### 2.2 奖励函数修正（过渡期）

| 实验 | 日期 | 内容 |
|------|------|------|
| 奖励分解分析 | 07-14~15 | 定位 `ee_ratio` 下"只收集、不转发"的策略退化 |
| 阶段 C 诊断 | 07-26 | 完成 reward vs 论文 Ξ 一致性验证 |

**关键发现**：
- `ee_ratio`（历史默认）下：UAV 学会从 GU 收集数据但不向 RBS 转发，转发/接收比 ~1.5%
- 根因：`ee_ratio` 的分子包含"接收量"，策略只需最大化接收即可获得高奖励
- 修正：新增 `paper_xi` 模式——分子仅含 RBS 转发量，严格对齐论文 Eq.9
- 验证：`paper_xi` 下转发/接收比 → 54.75%，reward 与论文 Ξ 相关系数 ≈ 0.9999997

## 3. 方法论决策

### 3.1 奖励模式演变

```
ee_ratio (历史默认)    →  paper_xi (当前标准)
(接收+转发) / 能耗         转发 / 能耗

问题：UAV 学会"只收集不转发"    修正：严格对齐论文 Eq.9
转发率 ~1.5%                    转发率 → 54.75%
                                与论文 Ξ 相关系数 ≈ 0.9999997
```

**当前约定**：
- 正式实验统一使用 `paper_xi`
- 旧 `ee_ratio` 仅保留作为消融基线
- 不跨奖励版本、环境版本或统计口径直接计算提升比例

### 3.2 算法演进逻辑

```
主线（投稿核心）：
  MADDPG ──→ Hier-NoDyna ──→ Hier-DynaQ
  单层基线     分层对照         分层+环境模型

对照分支（扩展分析）：
  ├── iDDPG       (消融：CTDE 的贡献)
  ├── MATD3       (消融：Twin Critic 的贡献)
  └── CoP-MADDPG  (消融：通信预测的贡献)
```

### 3.3 Dyna-Q 实现规范

| 组件 | 当前实现 | 说明 |
|------|---------|------|
| 世界模型 | 前馈网络 `(s,a) → (r_pred, s_pred)` | MSE 监督训练 |
| 规划步数 | Dyna-K = 1（当前默认） | 消融实验将扫 K∈{1,3,5,10} |
| 模型预热 | warm-up = 32 | 规划前至少积累 32 条真实经验 |
| 训练方式 | 批量 GPU 推理 + 梯度累积 | 消除逐样本 CPU/GPU 往返 |
| 规划范围 | 仅更新下层 DQN | 上层 MADDPG 不参与虚拟经验 |

## 4. 实验方案

### 4.1 阶段 B：统一三算法 × 5 种子（当前阶段）

**目的**：为核心三算法补齐统计效力，形成可投稿的证据链。

**冻结配置**：

```
┌─────────────────────────────────────────────┐
│  算法：     MADDPG / Hier-NoDyna / Hier-DynaQ │
│  种子：     42, 123, 2026, 3407, 8888        │
│  奖励：     paper_xi                          │
│  轮次上限： 8000 episodes                     │
│  提前停止： patience=1500, window=500          │
│  场景：     Case 1                            │
│  GPU：      1                                 │
│  总任务数：  3 算法 × 5 seeds = 15 次          │
└─────────────────────────────────────────────┘
```

**记录指标**（每 seed 逐 episode）：

| 指标 | 含义 |
|------|------|
| `reward` | RL 奖励信号 (paper_xi × scale − collision) |
| `paper_xi` | 论文定义的系统能效 Ξ (RBS转发量/总能耗) |
| `data_received` | GU→UAV 感知吞吐量 |
| `data_sent_to_rbs` | UAV→RBS 交付吞吐量 |
| `total_energy` | 飞行 + 感知 + 转发能耗 |
| `collision_count` | UAV 间距 < d_min 的次数 |
| `forward_receive_ratio` | 转发/接收比 (策略质量指标) |
| `model_loss` | 世界模型预测误差 (仅 Dyna-Q) |

**显著性检验计划**：

| 检验项 | 对比 | 假设 |
|--------|------|------|
| 最终奖励 | MADDPG vs Hier-NoDyna | H₁: 分层架构显著优于单层 |
| 最终奖励 | Hier-DynaQ vs Hier-NoDyna | H₀: Dyna-Q 不提升最终性能 |
| 收敛轮次 | Hier-DynaQ vs Hier-NoDyna | H₁: Dyna-Q 显著加速收敛 |
| 前500轮奖励 | Hier-DynaQ vs Hier-NoDyna | H₁: Dyna-Q 早期样本效率显著更高 |

**执行状态**：代码已冻结，等待 GPU 空闲。

### 4.2 阶段 D：Dyna-Q 消融实验

**目的**：揭示规划步数 K 与模型预热 warm-up 各自对样本效率的贡献。

**消融矩阵**：

```
步骤 1 — Dyna-K 消融（固定 warm-up=32）：
  K ∈ {1, 3, 5, 10} × seeds ∈ {42, 123, 2026, 3407, 8888}
  → 4 × 5 = 20 次运行

步骤 2 — warm-up 消融（固定最优 K）：
  warm-up ∈ {0, 32, 64, 128} × seeds
  → 4 × 5 = 20 次运行

步骤 3 — 场景扩展（固定最优组合）：
  Case 2 × seeds
  → 1 × 5 = 5 次运行
```

**额外指标**（比阶段 B 多记录）：

| 指标 | 用途 |
|------|------|
| 世界模型 reward 预测 MSE | 诊断模型质量 |
| 世界模型 state 预测 MSE | 诊断模型误差累积 |
| 训练墙钟时间 | 区分"样本效率"与"计算效率" |
| GPU 利用率 | 评估批处理化收益 |

**代码状态**：`scripts/run_dyna_ablation.py` 已就绪，支持参数化 sweep。

**启动条件**：阶段 B 完成 → 1-5 episode 冒烟测试 → 正式消融。

### 4.3 阶段 E：扩展基线诊断（待定）

MATD3 与 CoP-MADDPG 当前显著低于 MADDPG，需要独立超参数搜索和训练路径验证后再决定是否纳入论文。

## 7. 潜在风险

| 风险 | 可能性 | 影响 | 缓解措施 |
|------|:---:|------|------|
| 5 种子下 MADDPG 方差仍然过大 | 中 | 分层 vs 单层的显著性检验失效 | 预先规划非参数检验 (Mann-Whitney) 作为备选 |
| Dyna-Q 最终奖励优势在 5 种子下仍不显著 | 高 | 论文创新点需聚焦样本效率而非最终性能 | 已有预案——WCL 主张明确以"样本效率"为核心 |
| Dyna-K 消融无最优区间 | 低 | K 对性能影响微弱 | 增大 K 范围 (1,5,10,20) 或换度量指标 (如 AUC) |
| GPU 空闲窗口不确定 | 中 | 阶段 B 启动延迟 | 监控服务器状态，优先使用单 GPU |
| MATD3/CoP-MADDPG 需独立调参 | 高 | 阶段 E 工作量超出预期 | 论文可以不纳入这两类基线，只聚焦三算法主线 |
