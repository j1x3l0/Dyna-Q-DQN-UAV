## 2. 最新相关研究对照

### 2.1 直接竞争：分层 MARL + UAV 轨迹规划（2024-2025）

这些是最需要区分的论文——它们都使用了"上层轨迹+下层接入"的双层架构：

| 论文 | 发表 | 架构 | 与本项目的关系 |
|------|------|------|---------------|
| **HMADDPG** (原论文) | Sensors 2023 | 上层 MADDPG + 下层 DQN | **本项目的起点**——结构完全相同。该文在结论中明确写 "integrating model-based local information to accelerate convergence" 作为 future work |
| **MAHDRL** | IEEE TMC 2024 | 上层 SAC + 下层 DQN | **最接近的竞争工作**。用于 UAV 无线供能通信，上层决定轨迹+能量传输，下层决定数据收集。与本项目场景高度重叠。**关键区别**：没有环境模型/规划 |
| **HRL-TPRA** | IEEE TCOM 2025 | 外层轨迹 + 内层通信 | 分层 RL 联合轨迹规划与资源分配。优化 AoI + 数据收集量 |
| **HQMIX** | IEEE TVT 2025 | 两层 HDQN + mixing network | 上层调度、下层路径规划。CTDE 架构 |
| **NO-HRL** | IEEE TITS 2025 | 两层 DRL + 解耦训练 | 目标是最小化 AoI，面向数据时间敏感 IoT |
| **DTH-MADDPG** | J King Saud Univ 2025 | 双时间尺度 MADDPG | 多 UAV 协同搜索（非通信场景，但架构类似） |

**核心判断**：分层 MARL + UAV 轨迹规划在 2024-2025 已是**红海**。仅凭分层架构无法发表。但所有上述工作都是 **model-free** 的——没有环境模型、没有虚拟经验规划。**这正是本项目的差异化空间**。

### 2.2 Dyna-Q 在无线网络中的应用（2024-2025）

| 论文 | 发表 | 应用场景 | 与 UAV 通信的重叠度 |
|------|------|------|:---:|
| **DQNOCHN** | Springer 2024 | Dyna-Q 优化 RF 能量采集充电效率 | 低（不涉及 UAV, 不涉及通信调度） |
| **NOMA Dyna-Q** | IEEE Conf 2025 | Dyna-Q 用于 NOMA 干扰环境能量分配 | 低（不涉及 UAV, 不涉及轨迹） |
| **MA-TDQ** | IEEE TNSE 2024 | 多智能体迁移 Dyna-Q 用于水下声学通信 | 中（多智能体 + 通信资源管理，但场景完全不同） |

**核心判断**：Dyna-Q 在无线网络中有零星应用，但**没有任何工作将 Dyna-Q 应用于 UAV 轨迹规划、传输调度和接入控制的联合优化**。这是一个真实的研究空白。

### 2.3 新颖性定位：一句话

> 首次将 Dyna-Q 环境模型规划引入分层 MARL 框架，用于加速 UAV 辅助无线传感器网络中下层接入控制策略的收敛。该方法直接回应了 2023 年 HMADDPG 原论文提出的 "integrating model-based local information to accelerate convergence" 的呼吁。

## 3. 方法严谨性审查

### 3.1 奖励函数

| 检查项 | 状态 | 说明 |
|--------|:---:|------|
| 奖励定义与论文 Eq.9 对齐 | ✅ | `paper_xi` 模式：reward = RBS转发/总能耗，相关系数 0.9999997 |
| 奖励缩放合理性 | ⚠️ | `reward_scale=50` 将原始 bits/J 放大到 ~3-5 范围。论文中需解释选择依据 |
| 碰撞惩罚融入方式 | ⚠️ | 碰撞惩罚作为减法项加在能效比之外——与原论文公式 (11) 一致，但需论证此设计的梯度特性 |
| `denom_epsilon=1e-6` 合理性 | ✅ | 防止除零，标准做法 |
| 上下层奖励分离 | ❌ | 当前上下层共享同一环境奖励。2023 原论文中上下层有独立奖励 (Eq.14, Eq.16)。这是一个**方法论偏差** |

### 3.2 物理模型

| 检查项 | 状态 | 说明 |
|--------|:---:|------|
| 噪声功率 | ✅ | 已修正为 `1e-12 W` (-90 dBm)，对齐论文 |
| Rician K-factor | ✅ | K=10，LOS 归一化，NLOS 未归一化 |
| 能量采集模型 | ⚠️ | 线性 μ=0.5——论文本身用线性，但审稿人可能指出真实整流天线是非线性的。需在 limitations 中声明 |
| 波束成形简化 | ⚠️ | 使用归一化信道向量代替最优波束成形——这是对原论文的简化。需声明并讨论影响 |
| 信道时间相关性 | ⚠️ | i.i.d. 每时隙重采样——没有多普勒/阴影。Rician 信道在相邻时隙间实际存在相关性。这不影响"算法对比"的内部有效性，但影响"物理真实性" |

### 3.3 算法实现

| 检查项 | 状态 | 说明 |
|--------|:---:|------|
| 种子可复现性 | ✅ | 6 条独立 SeedSequence RNG 流 |
| Dyna-Q 规划范围 | ✅ | 仅更新下层 DQN——合理：上层 MADDPG 状态转移无闭式物理模型 |
| 模型预热 | ✅ | warm-up=32，防止未训练模型产生噪声虚拟经验 |
| 批量 GPU 推理 | ✅ | 消除逐样本 CPU/GPU 往返 |
| NoDyna 对照的公平性 | ⚠️ | NoDyna 与 Dyna-Q 是两个独立类，存在 ~300 行代码重复。虽然不是实验偏差，但增加维护风险 |
| 超参数搜索 | ❌ | 所有算法使用统一超参数 (LR=1e-4, batch=32, hidden=64)。审稿人可能问"是否每个算法都用最优超参数？" |

## 4. 创新点重新定位建议

### 当前表述（不推荐）

> "提出分层多智能体强化学习框架，上层 MADDPG 处理 UAV 轨迹，下层 DQN 处理 GU 接入"

**问题**：2024-2025 已有 4+ 篇 IEEE Trans 论文做同样的分层架构。

### 推荐表述

> "针对 HMADDPG [ref: 2023 Sensors paper] 下层 DQN 样本效率低的问题，引入 Dyna-Q 环境模型规划：利用 GU 缓冲区/能量动态的闭式物理方程训练世界模型，在真实交互间隙生成虚拟经验加速 DQN 收敛。在相同真实交互步数下，Dyna-Q 达到 90% 峰值性能所需的训练轮次比无模型对照减少约 36%，且世界模型训练仅使用真实经验（无需额外环境交互）。"

**三个卖点**：
1. **问题驱动**：直接回应 2023 原论文的 "future work" 呼吁
2. **方法简洁**：轻量级 Dyna-Q（~8500 参数），不需要大型世界模型
3. **可解释性**：世界模型基于物理方程，预测误差可追踪

## 6. 底线判断

| 问题 | 答案 |
|------|------|
| **能投 WCL 吗？** | 可以——但需要完成阶段 B+D 并重新定位创新点 |
| **最大的被拒风险是什么？** | 审稿人认为"分层架构+MADDPG+DQN"不是新东西 → 必须把叙事焦点从分层架构转移到 Dyna-Q 加速 |
| **Dyna-Q 够新吗？** | 在 UAV 通信场景中——**是的**。2024-2025 无线网络中有 3 篇 Dyna-Q 论文，但没有一篇用于 UAV 轨迹+调度+接入联合优化 |
| **最危险的竞争论文？** | MAHDRL (IEEE TMC 2024) — 同样是双层架构用于 UAV 无线供能通信。必须与之明确区分：MAHDRL 是纯 model-free，本项目是 model-based |
| **现在最缺什么？** | 5 种子的统计证据 + Dyna-K 消融 + 创新点叙事的重新定位 |
