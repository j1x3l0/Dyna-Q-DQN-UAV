# 与 2023 原论文（HMADDPG）的差异与新增贡献

> 起草：2026-08-04。基于 `论文叙事框架与贡献定位_20260727.md` 的锁定叙事，
> 并同步阶段 D 实际完成的消融口径（K∈{1,5} 配对 + warm-up 门控）。

## 一、问题来源（一致性）

本项目的问题定义与原论文相同：多 UAV 联合轨迹规划、传输调度、接入控制的系统能效优化。
**研究动机直接回应原论文结论中明确的 future work**：

> "the hierarchical DRL scheme still requires long training time for the lower-layer DQN within each upper-layer decision epoch, suggesting integrating model-based local information to accelerate convergence."

## 二、与原论文的差异

| 维度 | 原论文（Sensors 2023，HMADDPG） | 本项目 |
|---|---|---|
| 下层学习方式 | 纯 model-free DQN 经验回放 | **Dyna-Q：世界模型 + 虚拟经验**，只规划下层离散决策 |
| 世界模型 | 无 | GU 缓冲区/能量闭式方程监督训练的前馈网络（~8500 参数），非黑箱 |
| 规划范围 | 无 | **仅下层**：上层 MADDPG 的连续轨迹转移缺乏可靠闭式模型，不参与虚拟规划 |
| 核心指标 | 原始 reward | `paper_xi`（RBS 实际交付 / UAV 总能耗），修正"只收集不交付"偏差 |
| 统计证据 | 少量 seeds | 核心三算法 **5 个配对 seeds** + 精确置换检验 + Holm 校正 |
| 消融 | 无系统消融 | Dyna-K（正式 **K=1 vs 5** 配对）、warm-up（0/32/64/128 门控，冻结 128） |
| 扩展基线 | — | MATD3、CoP-MADDPG 统一修复+调参后同口径对比 |

## 三、四项贡献（锁定，与叙事框架一致）

1. **引入局部世界模型**：在下层引入基于 GU 缓冲区动态与能量采集闭式方程的局部世界
   模型，监督训练，不使用黑箱潜在空间预测；
2. **仅对下层离散决策虚拟规划**：Dyna 规划严格限定在下层 DQN 的接入控制；上层轨迹
   转移不生成虚拟经验，避免连续空间模型误差放大；
3. **三维消融分离增益来源**：
   - MADDPG vs NoDyna → 分层架构的收益（阶段 B）；
   - NoDyna vs Dyna-Q → 模型规划的增量收益（阶段 B，描述性收敛加速）；
   - Dyna-K 消融 → 规划步数边际效应（阶段 D 正式 K=1 vs 5，配 5 seeds）；
4. **多维证据链**：同时报告样本效率（90% 峰值所需真实轮数）、Ξ、世界模型误差、
   墙钟成本、吞吐/能耗分解与碰撞。

## 四、表述边界（照抄叙事框架 §4，投稿前必须遵守）

| 表述 | 是否可用 | 说明 |
|------|:---:|------|
| "在相同上下层网络结构下，Dyna-Q 相比无模型对照加速收敛" | ✅ | 阶段 B 5-seed 描述性趋势（1.59×），**不可写"显著"**（Holm p=0.3125） |
| "Dyna-Q 在不牺牲最终能效的前提下减少真实交互" | ✅ | 与 NoDyna 末值持平（512.75 vs 515.02） |
| "显著提升最终能效 / 显著加速收敛" | ❌ | 5 seeds 最小可达 p=0.0625，统计不显著 |
| "优于所有现有方法 / 首次提出分层 MARL" | ❌ | 高风险绝对表述；分层架构是 baseline 不是贡献 |
| "UAV 通信中完全空白" | ❌ | 改为"据检索，尚未发现将 Dyna-Q 应用于该联合优化的工作" |
