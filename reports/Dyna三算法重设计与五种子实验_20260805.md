# Dyna 三算法重设计与五种子实验

## 共同修正：决策一致的下层转移

旧训练保存 `(z_t, a_t, r_t, s_{t+1})`，其中 `z_t` 是上层移动后的下层决策
状态，`s_{t+1}` 却是下一次上层移动前的状态。新实验延迟完成经验，保存
`(z_t, a_t, r_t, z_{t+1})`；`z_{t+1}` 是下一次下层真正采取动作的状态。
episode 终止转移仍使用 `done=True`，因此其下一状态不参与 Bellman bootstrap。

所有候选和 NoDyna 基线均使用该修正，旧结果目录不覆盖、不混用。

## 三种新算法

### DC-RBD：Decision-Consistent Robust-Budget Dyna

- Bellman 模型误差使用批内中位数绝对偏差（MAD）归一化，尺度下限为 1；
- 规划概率从 2% 爬坡到 5%，不再允许全局门控永久关闭；
- 每次从 8 个候选模型样本中保留误差最低的 50%；
- 模型更新到下层 DQN 的学习率为真实更新的 10%；
- 不使用反事实动作。

该方法检验“小而稳定的模型预算 + 稳健误差筛选”能否解决 BCAD 几乎零规划的问题。

### DC-RAD：Decision-Consistent Real-Anchored Dyna

- 规划概率从 2% 爬坡到 10%；
- 模型目标不直接替代真实目标，而采用
  `y = y_real + 0.25 * clip(y_model-y_real, ±MAD-scale)`；
- 使用 `1 / (1 + e^2)` 对模型样本逐元素加权；
- 模型更新学习率为真实更新的 25%。

该方法检验真实目标锚定能否在保留模型扰动的同时限制合成目标偏差。

### DC-UPD：Decision-Consistent Utility-Prioritized Dyna

- 规划概率从 2% 爬坡到 10%；
- 每次先抽取 32 个候选，再保留 8 个；
- 优先级为 `真实 TD 误差 / (1 + 模型 Bellman 误差)`；
- 使用 0.50 的真实目标锚定系数和稳健误差权重；
- 模型更新学习率为真实更新的 25%。

该方法将有限模型预算集中到“当前价值网络最需要学习、同时模型相对可信”的经验。

## 实验设计

- 方法：决策一致 NoDyna、DC-RBD、DC-RAD、DC-UPD；
- Seeds：42、123、2026、3407、888；
- 200 episodes/任务，Case 1，`paper_xi`；
- 4 方法 × 5 seeds，共 20 个配对任务；
- Dyna warm-up：25,600 个真实下层决策，即约 episode 128；
- 服务器并发：3 workers，单 GPU；
- manifest 每完成一个任务即原子更新。

## 验收指标

主指标为 episode 128--199 相对同种子 NoDyna 的配对奖励差，同时报告：

- last50、全程 AUC 与种子级 bootstrap 置信区间；
- 至少 4/5 seeds 的 post-gate 差值为正；
- 配对均值、中位数及 leave-one-seed-out 均值为正；
- 碰撞惩罚、RBS 数据、能耗分解，防止单个碰撞轨迹主导结论；
- 实际规划概率、筛选比例、稳健 Bellman 误差和墙钟开销；
- 无 NaN、OOM 或失败任务。

未满足稳健验收时不进入 500ep 扩量。
