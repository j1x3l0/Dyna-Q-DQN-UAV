# 论文叙事框架与贡献定位

> 定稿日期：2026-07-27
> 本文档锁定论文的核心叙事、贡献结构、表述边界与禁止用语。
> 后续所有实验设计、结果解读和论文写作必须以本文档为准。

---

## 1. 一句话核心主张

> 在既有分层 MARL 框架中引入模型驱动的 **Dyna-Q 虚拟规划**，仅对下层离散接入控制执行世界模型预测，提高 UAV 辅助无线传感器网络的真实交互样本效率。

**不是什么**：不是提出新的分层 MARL 架构；不是首次将分层用于 UAV 通信；不是全面超越所有 model-free 方法。

**是什么**：在已被验证的分层框架基础上，用轻量级 Dyna-Q 解决下层 DQN 样本效率低的问题——这个问题正是 2023 年 HMADDPG 原论文在结论中明确指出的 future work。

---

## 2. 问题来源与研究动机

### 2.1 起点

HMADDPG（Sensors 2023）提出的分层架构：上层 MADDPG（UAV 轨迹+调度）+ 下层 DQN（GU 模式+接入）。

该文的**明确未解决问题**（原文结论）：

> *"the hierarchical DRL scheme still requires long training time for the lower-layer DQN within each upper-layer decision epoch, suggesting integrating model-based local information to accelerate convergence."*

**本工作的动机就是回应这个呼吁。**

### 2.2 为什么选择 Dyna-Q 而非更复杂的世界模型

| 考虑维度 | Dyna-Q | Dreamer/MBPO/World Model |
|----------|--------|--------------------------|
| 模型复杂度 | 前馈网络 ~8500 参数 | 大型 transformer/SSM |
| 训练数据需求 | 少量真实 replay 样本 | 大量 episode rollout |
| 物理可解释性 | 基于 GU 缓冲/能量闭式方程监督 | 黑箱潜在空间预测 |
| 边缘部署可行性 | 适合 UAV 机载计算 | 通常需要 GPU 集群 |
| 与下层 DQN 的集成 | 直接调用 model_predict(s,a) | 需要重构训练管线 |

## 3. 四项贡献（锁定）

### 贡献 1：引入局部世界模型

面向 UAV 轨迹、调度和接入联合优化问题，在分层 MARL 框架的**下层**引入局部世界模型。该模型基于 GU 缓冲区动态和能量采集的闭式物理方程进行监督训练，不使用黑箱潜在空间预测。

### 贡献 2：仅对下层离散动作执行虚拟规划

Dyna-Q 规划严格限定在下层 DQN 的离散接入控制决策。上层 MADDPG 的连续轨迹转移**不参与**虚拟经验生成——因为 UAV 轨迹的状态转移缺乏可靠的闭式物理模型，模型预测误差会在连续空间中放大。这一设计使得模型规划只发生在可可靠建模的子空间。

### 贡献 3：通过三维消融分离增益来源

设置三组对照，将"分层架构的收益"与"模型规划的收益"明确分离：

| 对比 | 固定 | 变动 | 分离的效应 |
|------|------|------|-----------|
| MADDPG vs NoDyna | 模型规划无 | 架构单层→分层 | **分层架构的收益** |
| NoDyna vs Dyna-Q | 架构分层 | 模型规划无→有 | **Dyna-Q 规划的收益** |
| Dyna-K ∈ {1,3,5,10} | 架构+规划 | 规划步数 | **K 对样本效率的边际效应** |

### 贡献 4：多维度证据链

不只报告最终 reward，而是同时报告：
- **样本效率**：达到 90% 峰值性能所需真实交互轮次
- **系统能效 Ξ**：RBS 转发量 / UAV 总能耗（论文定义的核心指标）
- **世界模型误差**：reward 预测 MSE + state 预测 MSE 随训练的变化
- **墙钟成本**：训练总时长 + GPU 利用率
- **吞吐与能耗分解**：接收量、转发量、飞行能耗、碰撞次数

## 4. 表述约束（投稿前必须遵守）

### 4.1 当前表述的严格限制

| 表述 | 是否可用 | 条件 |
|------|:---:|------|
| "Dyna-Q 比 NoDyna 收敛快约 1.57 倍（516 vs 810 轮）" | ⚠️ 暂不可用 | 该数据来自旧奖励 + 仅 2 seeds。**必须等待阶段 B 的 5-seed `paper_xi` 结果重新确认**后才能写入 |
| "Dyna-Q 显著提升最终能效" | ❌ 禁止 | 2-seed 下仅 +0.4%，即使 5-seed 大概率不显著。改为"Dyna-Q 在不牺牲最终能效的前提下加速收敛" |
| "UAV 通信中完全空白" | ❌ 禁止 | 高风险绝对表述。改为"据我们所检索的范围，尚未发现将 Dyna-Q 应用于 UAV 轨迹-调度-接入联合优化的工作" |
| "首次提出分层 MARL" | ❌ 禁止 | 2024-2025 已有 4+ 篇 IEEE Trans。本工作的分层架构是 baseline，不是贡献 |
| "优于所有现有方法" | ❌ 禁止 | 未经全面对比。改为"在相同上下层网络结构下，Dyna-Q 相比无模型对照……" |

### 4.2 与竞争工作的对比用语

与 **MAHDRL（IEEE TMC 2024）** 的区分：
- MAHDRL：分层解耦（SAC+DQN），**纯 model-free**。贡献在于分层架构设计。
- 本文：分层框架不是核心创新。核心是 **下层 model-based planning + 虚拟经验**。分层架构是原论文 HMADDPG 的 baseline。

关键证据：**相同上下层网络结构下，Dyna-Q 相对于 NoDyna 的收敛速度差异、真实交互量和计算开销。** 这直接证明了模型规划的增量贡献，而非分层架构的贡献。

## 7. 审稿人预判问答

| 审稿人可能的质疑 | 预备回答 |
|------|------|
| "分层架构在 2024-2025 已有多个工作，新颖性在哪？" | 分层架构不是我们的贡献。贡献在于引入 Dyna-Q 加速下层 DQN 收敛——所有现有分层 MARL UAV 工作都是 model-free 的 |
| "为什么不和 MAHDRL 直接数值对比？" | MAHDRL 使用 SAC+DQN 结构，本文使用 MADDPG+DQN——上层算法不同导致不可直接对比。我们的消融在**相同网络结构下**对比 NoDyna vs Dyna-Q，隔离了模型规划的效应 |
| "为什么只在下层用 Dyna-Q？" | 上层 MADDPG 的 UAV 轨迹转移缺乏可靠闭式模型。GU 缓冲区/能量有明确的物理动态方程，模型预测可靠性高。仅对可可靠建模的子空间做规划 |
| "Dyna-K 为什么选这些值？" | K=1,3,5,10 覆盖从"几乎无规划"到"显著规划"的范围。更大 K 值可能引入模型误差累积——我们通过模型误差曲线验证这一点 |
| "墙钟时间更长了，样本效率有意义吗？" | 样本效率 ≠ 计算效率。在真实 UAV 部署中，每次环境交互涉及物理飞行和信道测量——真实交互的成本远高于 GPU 计算。样本效率度量的是"需要多少次真实交互"，这对物理部署至关重要 |
